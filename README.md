# Adidas Sales Performance Dashboard

An interactive data analytics project designed to track, visualize, and analyze multi-year retail performance metrics for Adidas across key regional markets.

## Dashboard Overview
<img width="1858" height="641" alt="Screenshot 2026-06-09 170503" src="https://github.com/user-attachments/assets/55e65b2f-e5a1-4e15-b444-8dde21b92e08" />


The project features a comprehensive dynamic sales dashboard that transforms raw commercial data into actionable business intelligence. It provides regional stakeholders with a multi-dimensional view of sales operations spanning 2023 to 2025 across territories including Egypt, Iraq, KSA, Lebanon, and Oman.

The analytical interface is structured around several core focal points:

* **Regional Revenue Distribution:** A localized breakdown showing total sales by country, allowing management to immediately identify primary revenue streams.
* **Temporal and Seasonal Trends:** Comprehensive timeline charts mapping year-over-year performance alongside macro-level monthly fluctuations to pinpoint peak purchasing seasons.
* **Fulfillment Channel Performance:** Comparative insights contrasting distribution channels, highlighting the volume driven by Online, Retail, Outlet, and Wholesale segments.
* **Product and Demographic Intelligence:** Deep dives into the top 5 globally sold items alongside specialized localized sub-reports (such as top-performing apparel and footwear in Egypt). It also tracks consumer demographic splits by gender.

## Key Features

* **Dynamic Data Filtering:** Fully integrated interactive slicers for Payment Method (Apple Pay, Cash, Credit/Debit Card, NetBanking, PayPal, UPI), Gender (Female, Male, Other), and Product Category (Accessories, Apparel, Footwear).
* **Cross-Filtering Capabilities:** Selecting any variable dynamically updates all visual metrics simultaneously across regional, product, and channel views.
* **Automated Aggregations:** Leverages underlying optimized Pivot Tables to seamlessly manage dense transaction records without performance lag.

## Technologies Used

* Microsoft Excel / Power BI (Data Modeling, Pivot Architecture, and Advanced Visualization)
* Data Source: Multi-year structured retail transaction ledger
